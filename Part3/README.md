#PROG5121 Part 3 – QuickChat Application

##Project Description

QuickChat is a Java console-based messaging application developed for PROG5121 Part 3. The application allows users to send, store, manage and view messages.

##Application Features

- Send messages to recipients using their cellphone numbers.
- Validate recipient cellphone numbers.
- Generate unique message IDs.
- Generate message hashes.
- Store messages for later access.
- Disregard messages that should not be sent.
- Display recently sent messages.
- Search for messages using their IDs.
- Search for messages by recipient.
- Delete stored messages using their hashes.
- Display stored message reports.

##Technologies Used

- Java
- Apache Maven
- JUnit

##Testing

The application includes unit tests for the Login, Message and Task classes.

##How to Run

1. Open the project in NetBeans.
2. Build the Maven project.
3. Run the main Java class.
4. Follow the instructions displayed in the console.
